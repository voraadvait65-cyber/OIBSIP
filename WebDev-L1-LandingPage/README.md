# NovaTech - Landing Page

## 📌 Project Overview

NovaTech is a modern and responsive landing page developed as part of the Oasis Infobyte Web Development and Designing internship.

The website is designed to present a fictional technology company and showcase its services, features, and digital solutions through a clean and professional interface.

## 🎯 Objective

The main objective of this project is to create a visually appealing and responsive landing page using HTML5 and CSS3.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive navigation bar
- Hero section
- About section
- Services section
- Features section
- Call-to-action section
- Footer section
- Smooth scrolling navigation
- Responsive design for desktop, tablet, and mobile devices
- Modern dark-themed user interface
